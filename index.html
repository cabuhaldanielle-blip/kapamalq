Introduction

The Kapisanan sa Pag-Iimpok at Paghihiram ng mga Kawani ng Pamahalaang Lungsod Quezon (KAPAMALQ) System is designed to manage core functions such as facilitating member loan withdrawals, tracking savings details, updating transaction records, and maintaining an overview of the loan portfolio, among other essential operations.

System Requirements

  • Operating System: Windows 10 (64-bit) version 1909 or later, or Windows 11.
  • CPU: Intel Core i5 (8th generation or newer) or AMD Ryzen 5 equivalent.
  • Storage: 256GB total capacity (or higher) with 50GB free space recommended.
  • RAM: 8GB minimum, 16GB recommended for optimal performance.
  • Network: Local Area Network (LAN) with minimum 100 Mbps speed (1 Gbps recommended).

Installation Instructions

Prerequisites

Ensure the following network settings are configured on your system:

  1. IPv4 Address: 192.168.1.111
  2. Subnet Mask: 255.255.255.0
  3. Default Gateway: 192.168.1.1
  4. Preferred DNS Server: 192.168.1.1

Steps to Configure Network Settings (if not already set):

  1. Open the Control Panel.
  2. Navigate to Network and Sharing Center > Change adapter settings.
  3. Right-click your active network connection and select Properties.
  4. Select Internet Protocol Version 4 (TCP/IPv4) and click Properties.
  5. Manually input the settings above.
  6. Click OK to save and exit.

Installing WampServer

  1. Download WampServer: Visit the official WampServer website and download the latest version compatible with your operating system.
  2. Run the Installer: Double-click the downloaded executable file to start the installation process. Follow the on-screen instructions. Use the default installation directory (usually C:\wamp64).
  3. Configure Apache Server: During installation, you may be prompted to select your default browser. Choose your preferred browser or skip this step to use the default. If required, allow Apache Server through the Windows Firewall: open Windows Security > Firewall & network protection, click Allow an app through the firewall, locate "Apache HTTP Server" in the list and ensure both "Private" and "Public" are checked.
  4. Set Up Apache Port: It is best practice to use a 4-digit port number, such as 1962. Open C:\wamp64\bin\apache\apache2.4.9\conf\httpd.conf in a text editor, locate Listen 80 and replace it with Listen 0.0.0.0:1962 and Listen [::0]:1962, then save and close the file. Additionally, open C:\wamp64\wampmanager.tpl and C:\wamp64\wampmanager.ini with Notepad/Notepad++, search for http://localhost/ (CTRL+F) and replace all occurrences with http://localhost:1962/. Save and close the files.
  5. Make WAMP Accessible to Network: Open C:\wamp64\bin\apache\apache2.4.9\conf\httpd.conf and ensure the following settings in the <Directory /> section:
    <Directory />
AllowOverride all
Require all granted
</Directory>
    Save and close the file.
  6. Complete Installation: Finish the setup and launch WampServer. The WampServer icon in the system tray should turn green, indicating all services are running.

Installing MySQL

  1. Download MySQL Installer: Visit the official MySQL website and download the "MySQL Installer for Windows."
  2. Run the Installer: Start the installation process by running the downloaded installer. Select the "Custom" installation type and include "MySQL Server" and "MySQL Workbench" in your selection.
  3. Configure MySQL Server: Set up a new MySQL Server instance using Standalone MySQL Server as the configuration type. Choose the default port (3306). Set a strong root password and optionally create additional user accounts.
  4. Start MySQL Server: Complete the installation and start the MySQL Server. Test the connection using MySQL Workbench or the command line.
  5. Make MySQL Accessible to Network: Open C:\wamp64\alias\phpmyadmin.conf in a text editor and update the configuration to:
    AllowOverride all
Require local
Order Deny,Allow
Deny from all
Allow from localhost ::1 127.0.0.1
Allow from 112.200.0.0/16
    Save and close the file.

Installing Visual C++ Redistributable (vcredist_x64.exe)

  1. Download Visual C++ Redistributable: Visit the Microsoft Download Center and download the latest version of vcredist_x64.exe.
  2. Run the Installer: Double-click the downloaded executable file to start the installation. Accept the license agreement and click Install. Wait for the installation to complete.

Post-Installation Verification

  1. Verify WampServer: Check the WampServer icon in the system tray — it should be green, indicating that all services are running. Open a web browser and navigate to http://localhost/. The WampServer homepage should appear.
  2. Verify phpMyAdmin: Open a web browser and navigate to http://localhost/phpmyadmin/. Log in using the MySQL root credentials set during the installation. Make sure that you can access and manage the MySQL databases.

Setting Root Password for MySQL

By default, the WAMP bundle does not set a password for the MySQL root user. Follow these steps to set a root password:

  1. Open MySQL Console: Click the WampServer icon in the system tray, select MySQL > MySQL Console, and press Enter when prompted for a password (as none is set by default).
  2. Set Root Password: At the mysql> prompt, type the following command and press Enter:
    SET PASSWORD FOR root@localhost = PASSWORD('EnterYourPasswordHere');
    Replace EnterYourPasswordHere with your desired password.
  3. Update phpMyAdmin Configuration: Navigate to the WampServer phpMyAdmin folder (e.g. C:\wamp64\apps\phpmyadmin\ ), open config.inc.php in a text editor, find the line 
    $cfg['Servers'][$i]['password'] = '';
    and update it to include your root password. Ensure AllowNoPassword is set to false:
    $cfg['Servers'][$i]['AllowNoPassword'] = false;
    Save and close the file.

Additional Configurations

  1. Edit my.ini: Open C:\wamp64\bin\mysql\mysql5.x.x\my.ini and update the password and lc-messages lines with your root password and preferred locale (e.g. lc-messages=en_PH).
  2. Enable Number Formatter (PHP intl): Copy files starting with icu* from <wamp_installation_path>/bin/php/php5.4.3/ to <wamp_installation_path>/bin/apache/apache2.2.22/bin/. Open php.ini and enable the intl extension: 
    extension=php_intl.dll
    Restart WampServer.
  3. Change Default Timezone in WAMP: Open php.ini, search for date.timezone and replace it with your preferred timezone, e.g. 
    date.timezone = Asia/Singapore

Start WAMP on Boot Up

The best way to ensure WampServer starts automatically upon system boot is to schedule a task that runs at user logon:

  1. Open Task Scheduler: Press Win + S, search for Task Scheduler and open it.
  2. Create a New Task: Click Create Task in the right-hand panel.
  3. Configure General Settings: Name the task WampServer and check Run with highest privileges.
  4. Set Trigger to Start Task at Logon: Go to the Triggers tab, click New, set the trigger to Begin the task: At log on, and click OK.
  5. Define the Action to Start WAMP: Go to the Actions tab, click New, select Start a program, browse to C:\wamp64\wampmanager.exe and set the Start in field to C:\wamp64. Click OK.
  6. Set Task Conditions: In the Conditions tab, uncheck Start the task only if the computer is on AC power and Stop the task if it runs longer than [x hours/minutes].
  7. Finalize and Restart: Click OK to save the task, close Task Scheduler, and restart your computer to test the configuration.

Alternative Method: Using Services

  1. Press Win + R, type services.msc and press Enter to open the Services window.
  2. Locate the services wampapache64 (Apache) and wampmysqld64 (MySQL).
  3. For each service: right-click, select Properties, set the Startup type to Automatic, then click Apply and OK.
  4. Restart your computer to verify both services start automatically.

User Interface Overview

I. Credit / Loaning System

The Credit / Loaning System interface is divided into two primary sections for ease of use: Members and Transactions.

1. Members

The Members section is focused on managing member information and related administrative tasks:

  1. Add New Member: Enables the addition of a new member to the system.
  2. Update Member: Facilitates the modification of an existing member's details.
  3. Edit Account Number: Allows changes to a member's account number.
  4. Edit Member Name: Provides the option to update member names.
  5. Edit Office Name: Updates the office name linked to a member's account.
  6. View Member Details: Displays comprehensive details for a selected member.
  7. Add/Update Co-Maker: Adds or updates co-makers associated with a member's account.
  8. Account Master List: Shows a complete list of all accounts within the system.
  9. Set to Inactive: Deactivates a member's account while retaining their records.
  10. Fixed Capital Contribution (CC) Office: Determines the fixed Capital Contribution (CC) of the members per office.
  11. Exceed Capital Contribution (CC) Buffer: Monitors and highlights when a predefined Capital Contribution (CC) buffer is exceeded. The EXCEED COUNT is prominently displayed for quick reference.
  12. Passbook Printing: Enables the printing of a member's passbook for transaction tracking.
  13. Ex-Member Account: Manages the accounts of former members.

2. Transactions

The Transactions section is dedicated to managing financial transactions and approvals:

  1. Loan: Facilitates the processing and evaluation of loan applications, including assessing the borrower's capacity to repay for regular and emergency loans, as well as ensuring compliance with the single borrower's limit (SBL).
  2. Withdraw: Facilitates fund withdrawal transactions.
  3. Verification: Ensures transaction details are accurate and complete. Flagged items, if any, are highlighted for attention.
  4. Voucher: Manages transaction vouchers, including generation and review.
  5. Withdrawal List: Displays a detailed list of withdrawal transactions.
  6. Edit Transactions: Allows authorized users to modify transaction details as needed.
  7. Post Audit: Displays audit-related items for review and action.
  8. Approval: Handles pending approvals for loans and other transactions.
  9. Monitor Status: Tracks the progress and status of loans, withdrawals, and other transactions.
  10. Check List: Provides a detailed checklist to verify transaction accuracy and compliance.
  11. Regular Inquiry: A general tool for accessing account and transaction information. Regular loans range from P5,000 – P250,000 (loan sample computation including the interest-of-loan, IOL).
  12. Emergency Inquiry: Specialized for urgent account or transaction-related inquiries. Emergency loans range from P5,000 – P15,000 (loan sample computation including the interest-of-loan, IOL).
  13. Print EIR: Prints the Effective Interest Rate (EIR) report for loans or transactions.
  14. Declaration Form: Generates a Membership Declaration Form (MDF) for fixed capital contribution.
  15. Consent Slip: Prints or updates standard consent slips. The consent slip signifies the member's agreement to have insurance payments for the regular loan deducted directly from their salary.
  16. Emergency Consent Slip: Prepares consent slips for emergency transactions. The consent slip signifies the member's agreement to have insurance payments for the emergency loan deducted directly from their salary.
  17. Slip Print/Edit/Delete: Manages printing, editing, or deleting various transaction slips.
  18. Emergency Loan (EL) Slip Print/Edit/Delete: Manages printing, editing, or deleting various emergency loan (EL) transaction slips.

Loan Summary

The Loan Summary Section provides a consolidated view of loan activities for the year, categorized into Regular Loans and Emergency Loans. It highlights the total amounts disbursed and the corresponding net amounts collected, enabling efficient monitoring and analysis of loan performance.

  1. View Loan: Displays detailed information about individual loans, including borrower details, loan type, repayment terms, and current status. These include the member's office, name, age, loan date, check no., maturity date, amortization, disbursement voucher (DV), promissory note (PN), capacity excess, loan amount and net amount (for both regular and emergency loans).
  2. View Loan Summary: Presents an aggregated summary of all loans within a selected timeframe, broken down by month and loan type.

Loan Summary Table Overview

The loan summary table provides a monthly breakdown of loan data with the following components:

  1. Month (Accountability): Indicates the specific month for which the loan transactions are recorded.
  2. Regular Loans: Amount — the total loan amount disbursed under regular loan programs during the month; Net — the actual net amount provided to members.
  3. Emergency Loans: Amount — the total loan amount disbursed under emergency loan programs during the month; Net — the actual net amount collected from repayments of emergency loans during the month.
  4. Total Month: Combines the total loan disbursement (amount) and actual amount (net) of loan provided from both regular and emergency loans for the respective month.
  5. Annual Summary: Regular Loans: total amount and total net for the year. Emergency Loans: total amount and total net for the year. Grand Total: aggregates the total disbursed loans (Amount) and total collections (Net) from both loan types for the entire year.

II. Accounting System

The Accounting System interface is designed for efficient financial management. It is divided into two sections:

1. Transactions

  1. Post Remittance: Processes the posting of remittances into the system. This also posts the transaction in the member's ledger which includes the official receipt (OR), remittances, acknowledgement receipt and general adjustment.
  2. Death Benefit (DB) Deduction: Handles deductions related to death benefits.
  3. Dividend (Cash/Check): Manages and calculates member dividends, including the master list for dividend computation.
  4. Check Remittance: Verifies and reviews remittance details per office.
  5. Death Benefit List: Displays and manages the list of members' beneficiary/ies, including the details and amount that the beneficiary will receive.
  6. Print Dividend Check: Prints the list of dividend checks of members for distribution.
  7. Cash Receipt: Records cash receipts into the system.
  8. Edit/Delete Receipt: Allows modifications or deletions of recorded receipts.
  9. Cash Disbursement: Handles cash disbursement transactions.
  10. Edit/Delete Disbursement: Enables editing or deletion of recorded disbursements.
  11. Adjustments: Processes financial adjustments on a monthly basis.
  12. Edit Request: Manages pending edit requests for transactions, with notifications for flagged items.
  13. SOA Summary: Displays a consolidated summary of the Statement of Accounts (SOA).
  14. Capital Contribution (CC) – SOA per Office: Generates SOA reports specific to each Capital Contribution.
  15. Regular Loan (RL) – SOA per Office: Provides SOA reports for RL (Regular Loan) categorized by office.
  16. Emergency Loan (EL) – SOA per Office: Prepares SOA reports for EL (Emergency Loan) by office.
  17. Create Voucher: Enables the creation of vouchers for financial/disbursement transactions.
  18. Voucher List: Displays a list of all created vouchers for reference or review.

2. Reporting

  1. Remittance Reports: Generates detailed reports of remittances.
  2. Past Due Reports: Highlights accounts or transactions that are overdue.
  3. Trial Balance: Displays the trial balance for account reconciliation.
  4. Financial Statements: Prepares comprehensive financial statements.
  5. SOA of TB Accounts: Generates the Statement of Accounts for Trial Balance accounts.
  6. Add Account Title: Allows the addition of new account titles.

III. Payroll System

The Payroll System focuses on managing employee payroll and related deductions:

  1. Payroll: Processes employee payrolls, including salary calculations and distribution.
  2. Statement of Deductions: Generates detailed statements outlining all employee deductions: SSS Loan, SSS Contributions, Pag-ibig Loan, Pag-ibig Contribution, Philhealth Contribution, Due from Employees & Officers, and KAPAMALQ deposit and loans (Regular/Emergency Loans if any).

IV. Scanned Files (Document Archival)

The Scanned Files provides a centralized location for managing scanned documents:

  1. Scanned Files: Stores, retrieves, and organizes scanned files for quick access and reference. For scanning are board resolutions, 201 files, individual vouchers, member's KYC, minutes of the meetings, office voucher and other transactions.

Remittance

The Remittance Section provides tools to track and analyze remittance records obtained from the accounting department. Users can monitor remittance details such as:

  1. Month (Accountability): Displays the specific month tied to the remittance.
  2. Date Remit: Shows the date on which the remittance was transmitted.
  3. OR Number: Refers to the official receipt number associated with the transaction.
  4. Amount: Indicates the remitted amount for the corresponding month.

These records, sourced from the accounting department, allow for accurate financial tracking and reconciliation.

  1. Renew List: Enables users to view and manage accounts that are due for renewal. This feature is essential for maintaining updated records and ensuring account activity.
  2. Loan Amort List: Provides detailed information about loan amortizations, helping users keep track of repayments and balances for active loans.
  3. Membership List: Displays a comprehensive list of all active members, allowing for quick access to member details and statuses.
  4. KYC Summary: The KYC (Know Your Customer) Summary provides an overview of member verification and compliance status. This ensures adherence to regulatory requirements and enhances member data integrity.
  5. Update Board Members: Facilitates the management and modification of board member details, ensuring the system reflects the current governance structure.

Using the KAPAMALQ System

I. Logging In to the System

  1. To use the KAPAMALQ System, kindly enter the appropriate username and password. After that, click the SUBMIT button.

II. Adding Members to the System

  1. To add a member's profile, go and click the ADD MEMBER button.
  2. The assigned personnel will input the necessary details prior to the member's information.
  3. Once done, click the SAVE AND ADD MEMBER button.

III. Updating Member's Profile

  1. To update a member's profile, go and click the UPDATE MEMBER button.
  2. Click the MEMBER NAME dropdown menu to select the name of the member, then click the SEARCH button to proceed.
  3. The assigned personnel can now update the member's profile.
  4. Once done, click the SAVE AND ADD MEMBER button.

NOTE: Only authorized staff can modify/update the members' information.

IV. Edit Account Number / Member Name / Office Name

  1. To edit/update an account number, member's name or office name, click either the EDIT ACCOUNT NUMBER, EDIT MEMBER NAME or EDIT OFFICE NAME button.
  2. Click the MEMBER NAME dropdown menu to select the name of the member, then click the SEARCH button.

NOTE: The EDIT ACCOUNT NUMBER, EDIT MEMBER NAME and EDIT OFFICE NAME have the same query page albeit different functions.

V. View Member Details

  1. To view the members' details, go and click the VIEW MEMBER DETAILS button.
  2. Click the MEMBER NAME dropdown menu to select the name of the member, then click the SEARCH button to proceed.
  3. From here, the user can view the member's account details such as: (a) Capital Contributions, (b) Consumption Loans, (c) Emergency Loans, and (d) Adjustments.

VI. Account Master List

  1. To view the Account Master List, go and click the ACCOUNT MASTER LIST button.
  2. To start, first select the desired OFFICE.
  3. Once done, click on the SEARCH button to view the master list of the selected office.

VII. Add/Update Co-Maker

  1. To add or update the Co-Makers, click on the ADD/UPDATE CO-MAKER button.
  2. Select the member's name, select the desired office, then click the SEARCH button to proceed.
  3. This will display the details of the member with their respective co-makers. The staff will then add or update the member's co-maker as per the request of the member. Once done, they can simply save afterwards.

VIII. Fixed CC Office &amp; Exceed CC Buffer

  1. To access the Fixed CC Office, click the FIXED CC OFFICE button; otherwise, to access the Exceed CC Buffer, click the EXCEED CC BUFFER button.
  2. First select the desired OFFICE, then click the SEARCH button to display the accounts of the designated office.
  3. Excess Cap Con displays all the members with excess capital contribution.

IX. Ex-Member Account

  1. To view the Ex-Member Account List, go and click the EX-MEMBER ACCOUNT button.
  2. To view the list of Ex-Members' Accounts, go and click the LIST EX-MEMBER ACCOUNT button.
  3. A list will appear showing all of the ex-members of KAPAMALQ.

X. Passbook Printing

  1. To access the Passbook Printing page, go and click the PASSBOOK PRINTING button.
  2. First, type in the name of the member and hit the SEARCH button.
  3. Once the details of the member appear, set the inclusive dates to proceed with the printing.
  4. Once done, click PRINT to proceed.

XI. Loan

  1. To access the Loan page, go and click the LOAN button.
  2. First, type in the name of the member and hit the SEARCH button.
  3. The details of the member will appear. The staff will encode the "capacity to pay of the borrower" first, in order to assess the financial capability of the employee to pay for their loan/s.
  4. Once done, click SAVE CAPACITY.
  5. After that, click the PRINT SBL/CTP.
  6. Finally, the staff will ask what kind of loan the member will avail: whether regular or emergency loan.

XII. Withdrawal Application Form

  1. To access the Withdrawal Page, go and click the WITHDRAW button.
  2. To start, first select the MEMBER'S NAME, then click on the SEARCH button to open the WITHDRAWAL APPLICATION FORM.
  3. Once on the Withdrawal Application Form, the user can now calculate the member's withdrawal — either Partial or Full withdrawal.
  4. Once done, the user will select the proper individual that will verify the member's withdrawal computation.
  5. Click the SAVE / PROCESS button to proceed and print the computation.
  6. A printout will appear containing the breakdown of the member's allowable withdrawal amount.

XIII. Withdrawal List

  1. To access the withdrawal list, go and click the WITHDRAWAL LIST button.
  2. On the withdrawal list, the staff has the ability to view the withdrawal amount released for the particular MONTH and YEAR for all the departments.

XIV. Verification

  1. To access the verification page, go and click the VERIFICATION button.
  2. The verification of transaction pertains to verifying if the transactions done are correct. If it is correct, click the VERIFY button; otherwise, click the CANCEL button.

XV. Edit Transaction

  1. To access the edit transaction page, go and click the EDIT TRANSACTION button.
  2. Search for the member's name, then click the SEARCH button to proceed and modify the transaction/s.

XVI. Voucher

  1. To access the voucher page, go and click the VOUCHER button.
  2. Once the voucher has been verified, it can now be printed. It will be verified again before it can proceed to printing the voucher.

XVII. Post Audit

  1. To access the post audit page, go and click the POST AUDIT button.
  2. Post Audit Verification is done by checking the account entries by the accountant.

XVIII. Approval

  1. To access the approval page, go and click the APPROVAL button.
  2. Approval of transaction is done by verification and approval of loan by the manager. This is the final step to generate the voucher.

XIX. Monitor Status

  1. To access the monitor status page, go and click the MONITOR STATUS button.
  2. Monitoring the transaction status also refers to tracking the transaction. Once done, the voucher will then be printed by the cashier.

XX. Check List

  1. To access the check list page, go and click the CHECK LIST button.
  2. To start, manually encode all the necessary details.
  3. Click the SAVE button to proceed. This will display all the transaction details.
  4. In order to print the report transactions, set the FROM & TO fields and click the PRINT TRANSACTIONS button.

XXI. Regular Inquiry &amp; Emergency Inquiry

  1. To access the regular loan or emergency loan inquiry, go and click either the REGULAR INQUIRY or EMERGENCY INQUIRY button.
  2. Once inside the Regular Inquiry or Emergency Inquiry page, the "LOAN SAMPLE COMPUTATION" page will appear. Search for the name of the member and click the SEARCH button.
  3. Once done, click the CALCULATE LOAN button to display the member/applicant's qualification and capacity to borrow. Through this, the staff will assess the amount given to the member.
  4. A sample computation will then be displayed to see the breakdown of the sample loan that the member could avail.

XXII. Print EIR

  1. To access the print EIR page, go and click the PRINT EIR button.
  2. First, search for the member's name and provide the necessary details of their particular loan, then click the SEARCH button.
  3. A breakdown of the loan calculation will appear. Once verified, simply click the PRINT EIR button.

XXIII. Declaration Form, Consent Slip, Emergency Consent Slip and Editing of Slips

  1. To access the declaration and consent slips page, use the corresponding buttons in the Transactions section.
  2. First, search the name of the member, then click the SEARCH button to start the search. The declaration form will appear and is ready for printing.
  3. The same process is also done in printing the CONSENT SLIP and the EMERGENCY CONSENT SLIP: search the name of the member and click the SEARCH button.
  4. A consent slip to deduct for the monthly loan amortization of the cooperative will be ready for printing afterwards. Click the SAVE button.
  5. Modifying and printing consent slips is done through either EL SLIP PRINT/EDIT/DEL for emergency loans or SLIP PRINT/EDIT/DEL for regular loans.

NOTE: The same process is also done in the EMER CONSENT SLIP.

XXIV. Post Remittance

  1. To access the post remittance page, click the POST REMITTANCE button.
  2. First, search for the member and click the SEARCH button to proceed.
  3. On this page, the staff can also add/update the Capital Contribution, Consumption Loan, Emergency Loan and Adjustments of the member.

XXV. Check Remittance

  1. To access the check remittance page, click the CHECK REMITTANCE button.
  2. Select the OR Number (month) and the desired office in the dropdown menus.
  3. Click the SEARCH button to view the details of remittances.

XXVI. DB Deduction

  1. To access the DB Deduction page, click the DB DEDUCTION button.
  2. Search for the MEMBER NAME and click the SEARCH button to proceed.

XXVII. Death Benefit List

  1. To access the death benefit list, click on the DEATH BENEFIT LIST button.
  2. The death benefit list summarizes deceased members' details and their corresponding death benefits received.

XXVIII. Dividend

  1. To access the dividend page, click the DIVIDEND button.
  2. First select the year from the dropdown menu, then click the SHOW button in order to proceed.
  3. This page provides for the printing and computation of dividends of the members.

XXIX. Print Dividend Check

  1. To access the printing of dividend check page, click the PRINT DIVIDEND CHECK button.
  2. Select the YEAR and OFFICE from the dropdown menu.
  3. Click SHOW to show the list of members.
  4. Click the PRINT CHECK button to print the check of the members.

XXX. Cash Receipt

  1. To access the cash receipt page, click the CASH RECEIPT button.
  2. To start, manually encode all the fields for the cash receipt details.
  3. Once done, click the ADD CASH RECEIPT button.
  4. In order to view if the encoded information is correct, select the MONTH and YEAR, then click VIEW FULL/VERIFY to verify the cash receipt.
  5. To export the report, click the EXPORT button.

XXXI. Edit Cash Receipt

  1. To access the edit/delete receipt page, click the EDIT/DELETE RECEIPT button.
  2. To modify the cash receipt, type in the OR/AR NUMBER or NAME.
  3. Click the SEARCH button to proceed. Once there, the user can now modify the details of the Cash Receipt.

XXXII. Cash Disbursement

  1. To access the cash disbursement page, click the CASH DISBURSEMENT button.
  2. To start, manually encode all the fields for the cash disbursement details.
  3. Once done, click the ADD DISBURSEMENT button.
  4. In order to view if the encoded information is correct, select the MONTH and YEAR, then click VIEW FULL/VERIFY to verify the cash disbursement.
  5. To export the report, click the EXPORT button.

XXXIII. Edit Cash Disbursement

  1. To modify the disbursement voucher, type in the DIV NUMBER.
  2. Click the SEARCH button to proceed. Once there, the user can now modify the details of the Disbursement Voucher.

Frequently Asked Questions (FAQ)

General Questions

Q: What is the KAPAMALQ System?

The KAPAMALQ System is designed to manage core functions such as member loan withdrawals, savings tracking, transaction records, archival of records and loan portfolio oversight. It streamlines administrative and financial tasks for the association.

Q: What are the system requirements for installing the KAPAMALQ System?

  • Operating System: Windows 10 (64-bit) version 1909 or later, or Windows 11
  • CPU: Intel Core i5 (8th generation or newer) or AMD Ryzen 5 equivalent
  • Storage: 256GB total capacity (50GB free space recommended)
  • RAM: 8GB minimum, 16GB recommended
  • Network: Local Area Network (LAN) with 100 Mbps minimum speed (1 Gbps recommended)

Installation and Setup

Q: How do I set up the KAPAMALQ System?

Refer to the Installation Instructions section in this manual. It includes steps for configuring network settings, installing WampServer, MySQL, and Visual C++ Redistributable, and verifying the setup.

Q: What should I do if the WampServer doesn't start?

  1. Check for port conflicts. Ensure no other applications are using the designated port (e.g., 1962).
  2. Verify Apache configuration and make sure all dependencies, like Visual C++ Redistributable, are installed.

Q: How do I access the system for the first time?

After installation, open a web browser and navigate to http://localhost:1962/. Log in using the credentials provided by your administrator.

Using the System

Q: How do I add a new member?

Navigate to the "Members" section in the system interface and click "Add Member." Fill in the required details and save the entry.

Q: How can I process a loan application?

Go to the "Transactions" section and select "Loan." Enter the member details, loan amount, and repayment terms, and then submit for approval.

Q: Where can I view all active accounts?

Use the "Account Master List" under the "Members" section to access a list of all active accounts.

Q: What if an erroneous entry has been made?

To rectify an erroneous entry, submit an edit request to the system administrator or designated personnel.

Troubleshooting

Q: What should I do if I forget my admin password?

Use the MySQL console to reset the password:

UPDATE users SET password=PASSWORD('new_password') WHERE username='admin';

Replace new_password with your desired password.

Q: I see a "Database connection failed" error. How do I fix it?

  1. Ensure the MySQL server is running.
  2. Check that the database credentials in the system configuration match your MySQL setup.

Q: My reports are not generating properly. What should I check?

  1. Ensure all required fields are filled before generating reports.
  2. Verify that the system server is operational and error-free.

Printing and Reporting

Q: How can I print a member's passbook?

Navigate to the "Passbook Printing" option under the "Members" section, select the member's account, and proceed with printing.

Q: Why are my reports missing data?

Incomplete reports often result from missing information in required fields. Verify all inputs before generating the report.

Performance and Optimization

Q: The system is running slowly. What can I do to improve performance?

  1. Upgrade your hardware to meet the recommended specifications (16GB RAM and 1 Gbps network speed).
  2. Close unnecessary background applications to free system resources.

Q: How do I prevent frequent crashes or freezes?

Regularly clear system logs and backups to free up storage. Ensure your operating system and hardware are up-to-date.

Maintenance and Updates

Q: How do I start WampServer automatically after a system reboot?

Configure WampServer to run at startup via Task Scheduler or set the Apache and MySQL services to "Automatic" in the Services management console.

Q: What should I do if data inconsistencies occur after a system update?

  1. Run a database integrity check using MySQL Workbench.
  2. Use the "Edit Request" section to review flagged transactions and correct inconsistencies.

Troubleshooting

This section provides solutions to common issues users may encounter while using the KAPAMALQ System. Follow the steps below to resolve problems effectively.

1. Common Installation Issues

Problem: WampServer or MySQL Not Starting

Cause:

  • Port conflict with another service.
  • Missing dependencies like Visual C++ Redistributable.
  • Incorrect configuration.

Solution:

  1. Verify that no other service is using the selected port (e.g., 1962): open Command Prompt and run netstat -a -n -o | find "1962". If another process is using the port, terminate it or select a different port in the WampServer configuration.
  2. Ensure Visual C++ Redistributable is installed by downloading it from the Microsoft Download Center.
  3. Recheck configuration files — Apache: ensure correct Listen directives; MySQL: validate database access credentials.

Problem: Unable to Access http://localhost/

Cause:

  • Firewall blocking the application.
  • Misconfigured network settings.

Solution:

  1. Allow Apache Server through the firewall: go to Windows Security > Firewall & network protection, click Allow an app through the firewall and enable Apache for both Private and Public networks.
  2. Verify network settings: IPv4 Address 192.168.1.111, Subnet Mask 255.255.255.0, Default Gateway 192.168.1.1.

2. Login and Account Access Issues

Problem: Forgot Admin Credentials

Solution:

  1. Open MySQL Console via WampServer.
  2. Run the following command to reset the password:
    UPDATE users SET password=PASSWORD('new_password') WHERE username='admin';
  3. Replace new_password with the desired new password.

Problem: Regular Users Unable to Log In

Cause:

Inactive user accounts or incorrect credentials.

Solution:

  1. Log in as an administrator.
  2. Navigate to the "Members" section and ensure the user account is active.
  3. Reset user passwords if necessary.

3. System Errors

Problem: PHP Errors or Blank Pages

Cause:

  • PHP errors not displayed.
  • Configuration issues.

Solution:

  1. Enable error reporting in the php.ini file:
    display_errors = On
  2. Restart WampServer.
  3. Reload the webpage to view error logs and fix issues as indicated.

Problem: "Database Connection Failed" Error

Cause:

  • MySQL server not running.
  • Incorrect database credentials.

Solution:

  1. Start MySQL via WampServer.
  2. Confirm credentials in the application configuration file match the MySQL setup.

4. Loan and Transaction Issues

Problem: Loan Application Details Not Saving

Cause:

  • Insufficient user permissions.
  • Database configuration issues.

Solution:

  1. Verify user roles and permissions in the "Members" section.
  2. Check the database table for corruption using MySQL Workbench.

Problem: Incorrect Totals in Loan Summaries

Solution:

  1. Use the "Post Audit" functionality to recalculate totals.
  2. Manually verify transaction records for discrepancies.

5. Reporting and Printing Issues

Problem: Reports Not Generating or Incomplete

Solution:

  1. Ensure all required fields are completed before submission.
  2. Check server logs for missing data errors.

Problem: Printing Errors in Passbook or Declaration Form

Solution:

  1. Confirm printer settings are correct.
  2. Use the "Slip Print/Edit/Delete" functionality to reprint the document.

6. Performance and Optimization

Problem: System Running Slowly

Cause:

  • Insufficient hardware resources.

Solution:

  1. Upgrade to recommended specifications: 16GB RAM, 1 Gbps network speed.
  2. Close unnecessary applications to free up resources.

Problem: Frequent Crashes or Freezes

Solution:

  1. Clear unnecessary logs and backups to free up storage space.
  2. Verify that the database server has adequate disk space.

7. System Maintenance

Problem: Unable to Start Services after a Reboot

Solution:

  1. Open Services (services.msc).
  2. Locate wampapache64 and wampmysqld64.
  3. Set both services to Automatic startup type.

Problem: Data Inconsistency after Updates

Solution:

  1. Run database integrity checks using MySQL Workbench.
  2. Review the "Edit Request" section for flagged issues.

8. Special Character Issues

Problem: Special characters cause errors or unexpected behavior

Cause:

The system may not handle or sanitize certain special characters (e.g., @, #, ', or &) in user inputs or data fields.

Solution:

  1. Avoid using special characters in input fields unless explicitly allowed (e.g., passwords or specific text fields). Report the specific character causing the issue to the administrator.
  2. Temporary workaround: replace special characters with alternatives or omit them when entering data.

9. Contribution Adjustment Issue

Problem: Salary increase affects the contribution, retroactively altering previous salaries and their respective contributions

Cause:

The system automatically adjusts contributions based on the new salary, even for historical records.

Solution:

  1. Manually check and verify contributions via the payroll system.
  2. Correct any discrepancies in historical records manually to ensure accurate reporting.
  3. Escalate to the administrator if automated adjustments persist to review and potentially fix system logic.
